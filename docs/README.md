# Documentación y referencias

Esta carpeta reúne el material de referencia del proyecto. Su contenido **no forma parte del sitio desplegable**.

## Contenido

- `prototipo/`
  - `SafeSchool-1.html`: primera versión/prototipo de la página en HTML (referencia de estructura, estilo y componentes iniciales).
- `referencia/`
  - `SafeSchool_v3.pptx.pdf`: referencia visual y de contenido (mensajes, tono y funcionalidad planteada, incluyendo el chatbot).

## Uso

Estos archivos sirven como base para guiar el rediseño y la implementación. Las mejoras y el código del sitio se desarrollarán en la raíz del proyecto (`index.html`, `assets/`, etc.) cuando se inicie la siguiente etapa.
